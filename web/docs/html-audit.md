# Сверка `html` → `web`

Анализировались страницы и JS в `html`, зарегистрированные маршруты `src/api/v1/api_router.py`, схемы, модели, CRUD и `src/api/deps.py`.

| Старый раздел                                   | Новый маршрут                            | Поддержка                                                                              |
| ----------------------------------------------- | ---------------------------------------- | -------------------------------------------------------------------------------------- |
| `auth`                                          | Любая страница без сессии                | Реальный OAuth-вход, проверка JWT, выход                                               |
| `campaigns`                                     | `/campaigns`, `/campaigns/:id`           | Списки, статистика, импорт, мастер, настройки, действия, сообщения, XLSX               |
| `tags`                                          | `/tags`                                  | CRUD, цвета, привязки API-ключей                                                       |
| `keys`                                          | `/keys`                                  | CRUD через `/api_keys`                                                                 |
| `users`, `users~`                               | `/users`, `/profile`                     | Администрирование, permissions и собственный профиль                                   |
| `android`                                       | `/android`                               | Список, все поля устройства, ручное создание, удаление                                 |
| Android accounts                                | `/accounts`                              | Архивы `.tar.gz`, лимиты (включая −1), паузы, статусы, редактирование                  |
| Android versions                                | `/versions`                              | Загрузка `.apk`, описание, редактирование, удаление                                    |
| `manual`                                        | `/manual`                                | Создание кампаний, API, шаблоны, webhooks, UTC                                         |
| `report`                                        | XLSX в кампании                          | Старый общий `/api/v1/report` не подключён; работающий отчёт — `/campaigns/:id/report` |
| `connections`, `devices`, `services`, `numbers` | Страница ограничения при прямом переходе | Соответствующие API не подключены в текущем сервере; фиктивные запросы не добавлены    |

## Особенности, учтённые при переносе

- Next.js по умолчанию перенаправляет URL без завершающего слеша. Для FastAPI отключён этот redirect; Route Handler прозрачно сохраняет пути, query, cookies, multipart и XLSX, а redirect upstream переписывается на тот же origin.

- Кнопки массового `/pause` на сервере нет: используется последовательный запрос к каждому `/campaigns/:id/pause`. Аналогично удаление тегов/ключей/устройств — по существующим DELETE маршрутам, а не отсутствующим legacy `/delete`.
- Очистка всех сообщений отделена от удаления выбранных: пустой DELETE `/campaigns/:id/campaign_dst` очищает всю кампанию. Выбранные сообщения удаляются исключительно с `{ids:[...]}`.
- Бэкенд возвращает ошибку парсинга загрузки иногда с HTTP 200: проверяются `type/msg`, а не только HTTP-код.
- Параметр пропуска заголовка файла фактически игнорируется сервером. UI не обещает его для файлов; для вставленного текста заголовок удаляется на клиенте.
- AI prompt отправляется как `prompt`, а не `system_prompt`, использовавшийся в старом wizard.
- Владельцы и options `/user`, пользователи, WA accounts, APK требуют superuser. Привязки кампаний, автоматическое сокращение и выбор OpenRouter-модели учитывают соответствующие permissions.
- UUID не имеет строковых LIKE-операторов в PostgreSQL; фильтр колонки UUID не предлагается.
- API Android PUT содержит существующую ошибку аргумента `db_obj` в `src/api/v1/endpoints/androids.py`. Редактирование устройства выключено с пояснением; сервер в рамках задачи не изменяется.
- Нет API для удаления временного файла `/upload/` контактов. Отмена прерывает fetch; уже сохранённый сервером временный файл может остаться. Для APK/WA повторное сохранение формы переиспользует уже загруженные файлы.
- Даты и расписание передаются в существующей UTC-семантике без неявного перевода в часовой пояс телефона.
- Цветовой `score` сообщения: `<0.4` — успех, `<0.7` — предупреждение, ≥0.7 или −1 — ошибка, NULL — неизвестно.

Существующие незакоммиченные изменения пользователя в корне репозитория, `html` и `frontend` сохранены. Реализация основана на совместимых React-компонентах существующего `frontend`, переведённых на Next.js и адаптированных под API и требования дизайна.
